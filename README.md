# EgmonWeather

Le ciel d'une ville, en trois dimensions.

On cherche une ville, le globe se tourne vers elle, puis le ciel montre le temps qu'il y fait. Le panneau donne les chiffres du moment, les 24 prochaines heures et les 7 jours.


## Fonctionnalités

- Recherche de ville, sans tenir compte des majuscules ni des accents
- Globe qui vise la ville, puis ciel 3D de cet endroit
- Pluie, neige, orage, brouillard, vent, jour et nuit
- Température, ressenti, humidité et prévisions
- Recherches récentes, favoris et position GPS
- Rue et ciel qui changent selon la latitude et la météo

## Stack

- JavaScript
- Vite
- Three.js
- Tailwind CSS
- Open-Meteo (sans clé)
